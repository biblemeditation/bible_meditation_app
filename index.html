      홈 화면에 앱처럼 두기

      홈 화면에 추가하면 아이콘을 눌러 바로 열 수 있고, 주소창 없이 앱처럼 보입니다.

      아이폰 · 아이패드 (사파리)지금 쓰는 기기

      1. 화면 아래쪽(아이패드는 위쪽)의 공유 버튼 을 누릅니다.
      2. 메뉴를 위로 올려 홈 화면에 추가를 누릅니다.
      3. 오른쪽 위의 추가를 누르면 홈 화면에 아이콘이 생깁니다.

      아이폰의 크롬에서는 주소창 오른쪽의 공유 버튼에서 같은 메뉴를 찾을 수 있습니다.

      안드로이드 (크롬)지금 쓰는 기기

      1. 오른쪽 위의 메뉴 버튼 을 누릅니다.
      2. 홈 화면에 추가 또는 앱 설치를 누릅니다.
      3. 설치(또는 추가)를 누르면 홈 화면에 아이콘이 생깁니다.

      삼성 인터넷에서는 아래쪽 메뉴 버튼에서 현재 페이지 추가 → 홈 화면을 누릅니다.
